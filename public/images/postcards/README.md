# Postcard photography

Place default postcard photos in this folder.

## For Connie Kang (and other photographers)

1. Add image files here (`.jpg` or `.webp` preferred).
2. Register each photo in `src/lib/photos.ts` with:
   - `src`: `/images/postcards/your-file.jpg`
   - `caption`: short title (e.g. `"Paris Sunset"`)
   - `credit`: e.g. `"Photography by Connie Kang"`

## Naming

Examples:
- `paris-sunset.jpg`
- `harbour-morning.webp`
- `lantern-evening.jpg`

## Orientation

Vertical / portrait crops work best (about 3:4), since the postcard front is tall.

Until real photos are added, SVG placeholders in this folder are used as defaults.
